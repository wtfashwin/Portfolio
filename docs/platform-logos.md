# Platform logo sources

These local assets identify the linked public platforms. They do not indicate endorsement. Retrieved on 8 October 2026.

Simple Icons SVGs are unmodified monochrome drawings from commit `98820a4dc8c363ca72fa2c0d294ea4a0a9bba75d`; CodePen uses release `14.15.0`, where that drawing remains available. Simple Icons applies [CC0-1.0](https://github.com/simple-icons/simple-icons/blob/98820a4dc8c363ca72fa2c0d294ea4a0a9bba75d/LICENSE.md); brand trademarks remain with their owners.

Other images come from favicon links published by the platforms themselves. ICO/JPEG files were decoded to PNG, retaining the original appearance; images larger than 64 pixels were capped at 64 pixels. These assets have no additional open-source license claimed here.

The logos use a pale neutral tile in the interface so black SVGs remain visible through both page themes. Preserve their aspect ratio and use `object-fit: contain`; no CSS color inversion is needed. Credly's official favicon is 16×16 pixels; the remaining PNGs are 32–64 pixels. SVGs have no scripts, event handlers, external references or embedded remote assets. All raster files were decoded and saved as PNG; the 14 files total less than 17 KB.
